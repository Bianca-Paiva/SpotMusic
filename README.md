# SpotMusic — Interface inspirada no Spotify

Projeto front-end que recria parte da interface do Spotify, com foco em layout, responsividade e interação utilizando HTML, CSS e JavaScript.

## ✨ Funcionalidades

- Cabeçalho com navegação e campo de pesquisa.
- Menu lateral com biblioteca, playlists e podcasts.
- Exibição dinâmica de artistas e álbuns populares.
- Carrosséis horizontais com navegação por setas.
- Menu dropdown para dispositivos menores.
- Barra de pesquisa expansível em telas menores.
- Layout responsivo.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura da página.
- **CSS3:** estilização, layout e responsividade.
- **JavaScript:** criação dinâmica dos cards e interações.
- **Google Fonts (Nunito):** tipografia.
- **Font Awesome:** ícones.

## 🚀 Como executar

1. Clone este repositório:

```bash
git clone https://github.com/Bianca-Paiva/Spotify.git
```

2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` em seu navegador.

Você também pode utilizar o VS Code com a extensão Live Server.

## ℹ️ Observação

Este projeto é uma reprodução visual e interativa de uma interface inspirada no Spotify, desenvolvida para fins de estudo.

Não possui integração com a plataforma oficial, reprodução real de músicas ou sistema de autenticação.
